# Experiment outputs

Run the CLI to create a new result directory. Each run stores its configuration,
data fingerprint, environment versions, split IDs, learned weights, training losses,
observed feedback, per-query predictions, statistical summaries, Markdown tables,
and plots. Existing completed/running result directories are not overwritten.

Generated results are excluded from version control. The downloadable local delivery
includes dry_run and ablation_smoke synthetic pipeline checks, not research findings.
Real benchmark/model evaluation requires local data, model weights and suitable compute.
